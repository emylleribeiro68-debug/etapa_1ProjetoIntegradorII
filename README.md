# SENSE — Sistema Inteligente de Monitoramento do Ambiente Escolar

## Objetivo

Desenvolver um sistema inteligente capaz de monitorar as condições do ambiente escolar e auxiliar os funcionários a identificar problemas antes que eles prejudiquem alunos e professores.

## O que é o sistema?

O SENSE será uma plataforma conectada a sensores instalados em diferentes ambientes da escola.

Os sensores poderão identificar informações como:

- Temperatura;
- Umidade;
- Iluminação;
- Ruídos excessivos;
- Presença de pessoas;
- Qualidade do ambiente;
- Possíveis problemas em equipamentos.

Essas informações serão enviadas para um painel central, onde os funcionários poderão acompanhar a situação de cada ambiente.

## Diferencial

O sistema não ficará apenas esperando alguém informar que existe um problema.

Ele poderá **identificar alterações no ambiente e gerar alertas automaticamente**.

Por exemplo:

> Uma sala começa a apresentar temperatura muito acima do normal. O sistema identifica a alteração e avisa a equipe responsável antes que o problema prejudique uma aula.

Outro exemplo:

> Um banheiro apresenta movimentação anormalmente baixa durante vários dias. O sistema pode indicar uma possível necessidade de verificação do local.

## Público-alvo

O sistema será destinado principalmente a:

- Funcionários;
- Equipe de manutenção;
- Coordenação;
- Direção;
- Responsáveis pela infraestrutura escolar.

## Como será desenvolvido?

O projeto será desenvolvido utilizando:

- **ESP32:** coleta dos dados dos sensores;
- **Sensores:** monitoramento dos ambientes;
- **Back-end:** processamento das informações;
- **Banco de dados:** armazenamento dos dados;
- **Front-end:** painel para visualização das informações;
- **Git e GitHub:** controle e organização do projeto.

## Resultado esperado

Criar um sistema capaz de transformar a própria escola em um ambiente monitorado, permitindo que os funcionários percebam problemas de infraestrutura com mais rapidez e possam agir antes que eles se tornem maiores.

A ideia principal é:

**A escola não espera o problema acontecer. O sistema identifica os sinais antes.**
