# Requisitos do Sistema

## Requisitos Funcionais

- **RF01:** O sistema deve coletar dados dos sensores instalados nos ambientes da escola.
- **RF02:** O sistema deve registrar temperatura, umidade, luminosidade, ruído e presença.
- **RF03:** O sistema deve armazenar os dados coletados em um banco de dados.
- **RF04:** O sistema deve apresentar os dados dos ambientes em um painel.
- **RF05:** O sistema deve identificar alterações fora dos padrões definidos.
- **RF06:** O sistema deve emitir alertas quando detectar uma situação anormal.
- **RF07:** O sistema deve permitir que funcionários visualizem os alertas.
- **RF08:** O sistema deve identificar o ambiente onde o problema foi detectado.
- **RF09:** O sistema deve registrar o histórico das alterações detectadas.
- **RF10:** O sistema deve permitir o cadastro e gerenciamento dos ambientes monitorados.
- **RF11:** O sistema deve permitir que funcionários marquem um alerta como verificado ou resolvido.
- **RF12:** O sistema deve apresentar relatórios sobre os dados coletados e problemas identificados.

## Requisitos Não Funcionais

- **RNF01 — Usabilidade:** O sistema deve possuir uma interface simples e fácil de utilizar.
- **RNF02 — Desempenho:** Os dados dos sensores devem ser processados e apresentados em um tempo adequado.
- **RNF03 — Segurança:** O sistema deve proteger os dados e permitir acesso somente a usuários autorizados.
- **RNF04 — Confiabilidade:** O sistema deve continuar funcionando mesmo quando algum sensor apresentar falha.
- **RNF05 — Disponibilidade:** O sistema deve estar disponível durante o período de funcionamento da escola.
- **RNF06 — Escalabilidade:** O sistema deve permitir a inclusão de novos sensores e ambientes futuramente.
- **RNF07 — Manutenibilidade:** O código deve ser organizado para facilitar futuras alterações e correções.
- **RNF08 — Compatibilidade:** O painel deve funcionar em computadores, tablets e celulares.
- **RNF09 — Integridade:** Os dados coletados devem ser armazenados de forma correta e consistente.
- **RNF10 — Privacidade:** O sistema deve evitar a coleta de informações pessoais desnecessárias.
